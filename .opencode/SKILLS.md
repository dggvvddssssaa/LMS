# OpenCode Skills

This project uses the following custom skills:

## Core Antigravity Skills
- **antigravity**: Core standards and aesthetics by Antigravity AI.
- **frontend-architect**: Large-scale Frontend application architecture and component design.
- **ui-ux-designer**: Modern UI/UX designs (Glassmorphism, Sleek Dark Mode, Gradients).
- **seo-expert**: SEO optimization, semantic HTML5, and Core Web Vitals.

## Specialized LMS & WebRTC Skills
- **lms-curriculum-manager**: LMS curriculum management, lessons, sections, and progress tracking.
- **lms-webrtc-auditor**: Quality and security auditing of WebRTC streaming connections in LMS.
- **webrtc-realtime-specialist**: WebRTC setup, live-streaming, socket communication, and Mediasoup integration.

## General Coding & Engineering Skills
- **bug-fixer**: Fullstack deep bug fixing (stack traces, 404/500 errors).
- **better-auth**: Security and architecture guidelines for modern authentication.
- **chrome-devtools**: Browser debugging, console diagnostics, and performance profiling.
- **code-review**: Code quality reviews, architecture sanity checks, and clean code enforcement.
- **databases**: Database management, query optimization, and schema design.
- **devops**: Deployment, Docker containerization, CI/CD, and server configuration.
- **git**: Advanced Git flow, branching strategies, commit linting, and conflict resolution.
- **mermaidjs-v11**: Flowcharts, sequence diagrams, and architecture visualization using Mermaid.js.
- **payment-integration**: Secure integration of payment gateways (Stripe, PayPal, etc.).
- **performance-optimizer**: Performance tuning, load-time reduction, and asset optimization.
- **prisma-db-architect**: Prisma ORM schema design, migrations, and seed automation.
- **react-best-practices**: Modern React hooks, state management, and lifecycle best practices.
- **security-checker**: Security audits, vulnerability scanning (XSS, CSRF, Injection).
- **tester**: E2E testing (Playwright), unit testing (Jest), and test manifest automation.
- **ui-improver**: UI polish, micro-animations, transitions, and detailed visual enhancements.
- **ui-styling**: Advanced styling systems, TailwindCSS, HSL-colors, and custom layouts.
- **ui-ux-pro-max**: Premium UX design standards and high-fidelity interactions.
- **web-design-guidelines**: Modern, professional web design principles and aesthetics.
- **web-testing**: Comprehensive cross-browser functional testing strategies.
