# LMS & Curriculum Manager

Expertise in the core domain model of the Learning Management System, including lessons, progress tracking, assignments, and certificates.

## Key Principles & Guidelines:
- **Curriculum Flexibility**: Support seamless curriculum configuration for 'recorded', 'live', and 'hybrid' course types without restrictive UI constraints.
- **Secure Certificate Generation**: Enforce strict progress checks before allowing a student to claim a certificate, ensuring no unauthorized certificates are issued.
- **Assignment Building & Grading**: Streamline the creation of diverse assignment types (MCQs, code submissions, text responses) and ensure solid backend validation of submission payloads.
- **Progress Tracking Integrity**: Accurately track student lecture consumption, quiz scores, and course completion states across services (`ProgressService` and `EnrollmentService`).
- **Template Customization**: Maintain robust customizable templates for certificates, ensuring text styling, background images, and signature locations render flawlessly.
